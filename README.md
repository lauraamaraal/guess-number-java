# Guessing Game 🎮

A simple number guessing game made in **Java**.

## 📌 About the Project

In this game, the computer chooses a secret number between **1 and 100**.

The player has **7 attempts** to guess the number.

After each attempt, the game gives a hint.

After the game ends, the player can choose to play again.

## 🛠️ Technologies

* Java
* `Scanner`
* `Random`

## ▶️ How to Run

1. Clone this repository:

2. Open the project in your Java IDE.

3. Compile and run the `JogoDeAdivinhacao.java` file.

4. Follow the instructions shown in the terminal.

## 🎮 How to Play

1. The computer generates a secret number from **1 to 100**.
2. Enter your guess.
3. You have **7 attempts**.
4. Use the hints to find the secret number.
5. At the end, choose:

   * `s` to play again
   * `n` to finish the game
